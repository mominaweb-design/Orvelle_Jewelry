# ORVÉLLE | Stainless Collection 2026

ORVÉLLE is a luxury-inspired stainless steel jewelry website featuring an elegant design, product collection, and shopping cart functionality. The website uses a soft color palette, modern typography, and responsive layouts to provide a premium shopping experience.

## Features

- Elegant and modern jewelry website design
- ORVÉLLE Stainless Collection 2026 branding
- Responsive layout for desktop and mobile devices
- Hero section with animated visual elements
- Product collection and category sections
- Our Promise section with four feature cards
- Product cards with images and pricing
- Add to Cart functionality
- Shopping cart panel
- Cart item quantity controls
- Remove items from cart
- Cart total price calculation
- Checkout button
- Smooth scrolling and hover animations
- WhatsApp contact button

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Playfair Display and Jost)

## Installation and Setup

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the website using Live Server or open the HTML file directly in your browser.

## How to Use

- Browse the jewelry collections.
- Explore product details and prices.
- Click **Add to Cart** to add products.
- Open the cart to view selected products.
- Update quantities or remove products.
- Review the cart total.
- Click Checkout to proceed.

## Customization

You can customize the website by editing:

- `index.html` for website structure and content
- CSS styles inside the `<style>` section for layout, colors, and styling
- JavaScript inside the `<script>` section for website interactions
- Product images, names, and prices for your collection

## Project Purpose

This project was created to showcase a premium stainless steel jewelry collection through a stylish and user-friendly online shopping website.
